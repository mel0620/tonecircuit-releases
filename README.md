# ToneCircuit

ToneCircuit is an Android patch editor for the Valeton GP-200. Connect your pedal to your phone with a USB-C data cable, browse your patches, edit sounds, and use a live-friendly view when you are playing.

This repository hosts public APK releases for ToneCircuit.

## Download

Get the latest APK from the releases page:

https://github.com/mel0620/tonecircuit-releases/releases/latest

If the latest link does not show an APK, open all releases here:

https://github.com/mel0620/tonecircuit-releases/releases

## What You Can Do

- Connect a Valeton GP-200 to an Android phone with USB-C.
- Browse GP-200 banks and patches.
- Follow patch changes from the pedal.
- Edit supported effects and parameters in real time.
- Turn blocks on or off while listening.
- Change effects from the app.
- Rename patches.
- Search the patch list by number or name.
- Move loaded patches up or down in the patch list.
- Arrange the signal chain.
- Use a focused Live view with large stomp-style controls.
- Use the app without an account or cloud sync.

## Requirements

- Android phone with USB-C.
- Valeton GP-200.
- USB-C data cable.
- The GP-200 must be powered with its own power supply.

Charge-only USB-C cables will not work. If the app cannot find the pedal, try another cable first.

## Install

1. Download the APK from the latest release.
2. Open the APK on your Android phone.
3. Allow installation from your browser or file manager if Android asks.
4. Open ToneCircuit.
5. Connect your GP-200 with a USB-C data cable.

## Known Limitations

ToneCircuit is an early release.

- Real-time edits can reach the pedal, but stored patch saving is still being verified across hardware and firmware behavior.
- Some GP-200 protocol behavior is reverse-engineered, so a few commands may still need more hardware testing.
- iOS is not supported by this APK release.
